# rtp-jitter

为游戏语音和实时回放整理 RTP 包，按序号重排后输出完整帧，只用 Go 标准库。

## 口径

- 序号按 16 位环形空间比较，跨回绕仍保持播放顺序。
- 同一序号只消费一次，缺口记录为丢包并挂在当前帧。
- marker 结束一帧；同一时间戳的包必须按序号拼接，帧间状态不能互相污染。
- 返回 `scanned`，处理量随收到的包数增长，不回扫历史帧。

## 不变量

- 输出帧内包序号严格递增。
- 重复包不会改变帧 payload 或丢包计数。
- 丢包只归属于发现缺口的当前帧。

## 输出契约

CLI 输出 JSON：`frames` 包含 `timestamp`、`payload`、`packets`、`lost`；另有 `dropped` 与 `scanned`。
